# Cartella dei documenti

Metti qui i file su cui vuoi interrogare il chatbot: `.pdf`, `.txt`, `.md`.
Le sottocartelle vengono esplorate ricorsivamente.

Il contenuto di questa cartella è escluso dal repository tramite `.gitignore`:
i documenti restano solo sul tuo computer e non vengono mai caricati su GitHub.

Al primo avvio l'indice viene costruito automaticamente. In seguito, ogni file
aggiunto, modificato o rimosso viene rilevato e reindicizzato da solo — non è
necessario ricostruire tutto.
